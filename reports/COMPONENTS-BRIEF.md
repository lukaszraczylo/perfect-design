## Hard rules (guard tests enforce them)
- Dependencies: only vue, reka-ui, tailwind-merge, pinia and relative imports in library source. No new package. Use lib/cva, lib/cn, lib/use-helpers, lib/icons.
- Universal contract: `class` wins (cn), cva variants exported as `xVariants`, `as`/`asChild` where it makes sense, `data-slot` on every root and part, attribute fallthrough, logical properties, icons via `<Icon :icon>` (FontAwesome-shaped data), tokens only (no hex/rgb, no gradients, glow, blur, glass, hover lift/scale, emoji, tracked all-caps, em dashes, buzzwords, invented people/quotes/numbers).
- Required parts and accessible names are enforced with the contract helpers (checks run in async onMounted, never in setup/render). Docs: `requires` entries.
- Variation prop names the matrix discovers: variant, size, tone, appearance, layout, density, shape, orientation, rounded, gap, columns, status, align, curve, fit, padding. Defaults render one stable look; unknown values fall back; every documented value has an example and tests.
- Accessibility: WCAG 2.2 AA, 24px targets (44px on coarse pointers), 16px form text on small screens, state never by colour alone, forced-colors fallbacks (borders/outlines), reduced motion, reflow at 320px, RTL. Works inside every style pack (`data-style`), especially `workbench` and `terminal` where spacing-based sizes shrink: keep targets >= 24px.
- Colour pairs only from those covered by packages/ui/src/__tests__/contrast.test.ts (it now also covers foreground/muted-foreground/primary on muted, secondary, accent, status colours on card, strokes at 3:1). Do not invent new pairings; if needed, add the pairing to that test first.
- Files per component, in `packages/ui/src/components/<group>/<Name>/`: `<Name>.vue`, `index.ts`, `<Name>.docs.ts` (default export ComponentDoc; props table must equal runtime props; >= 6 examples that pass strict-examples and axe guards; a11y, llmNotes, requires, related), `<Name>.test.ts` (good/bad/edge: empty, huge, hostile text, RTL, keyboard) and `<Name>.variants.test.ts`.
